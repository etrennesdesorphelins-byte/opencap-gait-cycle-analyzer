# OpenCap Gait Cycle Analyzer

OpenCapからダウンロードしたZIPファイルをブラウザ上で読み込み、対象試行を選択して左右のIC・Toe Offを設定し、
下肢関節角度（股関節屈曲・膝関節屈曲・足関節底背屈）と身体重心を101点に時間正規化してExcel出力するWebアプリケーションです。
身体重心は、ZIP内のスケーリング済みOpenSimモデル(.osim)を用いてブラウザ上で順運動学を計算して求めます。

全処理はブラウザ内で完結し、ZIP・動画・MOTデータを外部サーバーへ送信しません。

操作手順・算出方法・Excelの内容は、アプリ内の「使い方」ページ（`usage.html`）にまとめています。

詳細な仕様は以下を参照してください。

## セットアップ

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

`dist/` に静的ファイルが生成されます。GitHub Pagesへ`main`ブランチへのpushで自動デプロイされます
（`.github/workflows/deploy.yml`）。

## 使い方

1. OpenCap出力のZIPファイルをドラッグ＆ドロップ、またはボタンで選択
2. 解析対象のMOTファイルを選択
3. 表示するカメラ（Cam0, Cam1, ...）を選び、同期動画とフレーム操作で R IC / R Toe Off / L IC / L Toe Off を設定
   （何回でも設定可能。同じ側の連続するIC間を1歩行周期とし、Toe Offから立脚期%を算出します）
   （複数カメラを選ぶと並べて同時に表示され、全動画が同じ時刻に同期します）
4. 「解析実行」で左右の全歩行周期をそれぞれ101点へ時間正規化し、平均±SDを算出
   複数のZIPファイルを解析する場合は「6. 解析するZipファイルを追加する」でZIPを追加し、同様にイベントを設定します
   （解析は全てのZIPのイベント設定済みの試行をまとめて行います）
5. グラフで明らかなエラーの歩行周期（細線）をクリックして選択し、「この周期を除外」で解析から除外できます（「戻す」で復元）
6. グラフと時間・距離因子（歩行速度（全体）・歩幅・立脚/遊脚時間・荷重応答期/前遊脚期時間）を確認し、「Excelをダウンロード」で結果を出力（イベント一覧・周期ごとの値・平均±SD・周期ごとの正規化データ）
