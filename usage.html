OpenCap Gait Cycle Analyzer の使い方

対象バージョン 1.5.0。データは外部サーバーへ送信されず、全ての処理はお使いのブラウザ内で行われます。

1. このアプリでできること

OpenCap からダウンロードした ZIP ファイルを読み込み、同期動画を見ながら歩行イベント（初期接地・つま先離地）を設定して、 左右の歩行周期ごとの下肢関節角度・身体重心・時間距離因子を算出し、Excel に出力します。

  • 股関節屈曲・膝関節屈曲・足関節底背屈角度を、歩行周期 0〜100%（101点）に時間正規化し、平均 ± SD を表示
  • OpenSim モデルから身体重心（COM）の位置を算出
  • 歩行速度、左右の歩幅・立脚時間・遊脚時間・荷重応答期時間・前遊脚期時間を算出
  • 複数の ZIP（複数回の計測）をまとめて解析
  • グラフ上で明らかにおかしい歩行周期を選んで解析から除外

2. 準備

推奨環境

パソコンの Google Chrome または Microsoft Edge（最新版）。インストールは不要です。

OpenCap のデータ

OpenCap のセッションページからダウンロードした ZIP ファイルを、展開せずにそのまま使います。 アプリは ZIP 内の次のファイルを自動で探します。

ZIP内のファイル用途ない場合
OpenSimData/Kinematics/*.mot関節角度（試行の一覧）読み込めません（必須）
Videos/Cam*/InputMedia/{試行名}/{試行名}_sync.mp4同期動画動画なしで解析できます
OpenSimData/Model/*.osim身体重心身体重心のみ算出しません
MarkerData/{試行名}.trc歩幅（踵マーカー）モデルから計算したマーカー位置で代用

計測のコツ

  • 歩き始めと歩き終わりを除いた、定常歩行の区間が 2〜3 歩行周期以上映るように撮影すると解析しやすくなります。
  • 同じ歩行条件を複数回計測した場合は、複数の ZIP をまとめて解析できます（手順 6）。

3. 操作の流れ（早見表）

  1. ZIPを読み込むドラッグ＆ドロップまたはボタン
  2. 試行を選ぶMOTファイル（歩行の試行）
  3. 動画を確認カメラを選択、複数同時表示も可
  4. フレームを動かす±1・±10、スライダー
  5. イベントを設定R/L の IC・Toe Off を必要な数だけ
  6. ZIPを追加複数計測をまとめる場合（任意）
  7. 解析実行
  8. 結果を確認おかしい周期は除外
  9. Excelを出力

番号はアプリ画面の各項目の番号と同じです。

4. 操作手順

1. OpenCap ZIPファイルの読み込み

ZIP ファイルを枠内にドラッグ＆ドロップするか、「ZIPファイルを選択」を押して選びます。 読み込むと、ZIP 内の MOT ファイル（試行）の件数が表示されます。

2. 試行の選択

「試行 (MOTファイル)」から解析する試行を選びます。イベントを設定済みの試行には件数が表示されます。

選択すると、その試行について次の状態が表示されます。

  • 身体重心: 使用したモデルと総質量（体重と一致しているか確認できます）
  • 歩幅: 踵マーカーをどのファイルから取得するか

3. 同期動画

  • 「表示するカメラ」で表示する動画を選びます。複数選ぶと並べて同時に表示されます。
  • 全ての動画は MOT の時刻に合わせて同じフレームを表示します。動画の再生・一時停止も連動します。
  • 各動画の「＋」「－」で 100〜300% に拡大でき、拡大中は動画をドラッグして表示位置を動かせます。接地の瞬間を確認するときに便利です。
  • 先頭の動画が「基準」となり、Video Time の表示とイベントの記録に使われます。

4. フレーム / サンプル操作

「-10」「-1」「+1」「+10」ボタンまたはスライダーで、MOT のサンプル（フレーム）単位で移動します。 スライダーの下には、設定したイベントの位置が目印（右: 赤、左: 青。IC は長い線、Toe Off は短い線）で表示されます。

5. 歩行イベント（IC / Toe Off）の設定

動画を見ながらイベントのフレームに移動し、対応するボタンを押します。

ボタン設定するフレーム
R IC / L IC右 / 左の足が床に最初に接地した瞬間（Initial Contact）
R Toe Off / L Toe Off右 / 左のつま先が床から離れた瞬間
  • イベントは何回でも、どの順番でも設定できます。一覧に時刻順に並び、「移動」でそのフレームへ、「削除」で取り消しできます。
  • 同じ側の IC を 2 回以上設定すると、その間が 1 歩行周期になり、「歩行周期」の表に表示されます。
  • 立脚時間・遊脚時間には同側の Toe Off、荷重応答期・前遊脚期・歩幅には反対側の IC と Toe Offが周期内に必要です。左右とも全てのイベントを設定することをおすすめします。
  • 他の周期より 1.5 倍以上長い周期は色付きで表示されます。間の IC を設定し忘れていないか確認してください。
  • 試行を切り替えてもイベントは保持されます。

おすすめの手順: 定常歩行の区間で、例えば R IC → L Toe Off → L IC → R Toe Off → R IC … の順に、出てくるイベントを順番に設定していくと漏れが少なくなります。

6. 解析するZipファイルを追加する（複数の計測をまとめる場合）

  • 「Zipファイルを追加」で別の ZIP を追加すると、その ZIP が 2〜5 の操作対象になります。同じように試行を選んでイベントを設定してください。
  • 一覧の「編集」で操作対象の ZIP を切り替え、「削除」で解析対象から外せます。
  • 解析は、読み込んだ全ての ZIP のうち、イベントを設定した全ての試行の歩行周期をまとめて行います。

7. 解析実行

「解析実行」を押すと結果が表示されます。解析後にイベントや ZIP を変更すると結果は非表示になるので、もう一度「解析実行」を押してください。

8. 解析結果の確認と、エラー周期の除外

関節角度・身体重心のグラフの見方は次のとおりです（右: 赤、左: 青）。

  • 太線: 平均　帯: ± SD　細線: 各歩行周期　破線: 平均の Toe Off 位置

明らかにおかしい波形（イベントの設定ミスや計測エラー）がある場合は、その周期を除外できます。

  1. グラフの細線をクリックする（または上部の「歩行周期」の一覧から選ぶ）と、その周期が全てのグラフでオレンジ色の太線になります。
  2. 選択中の周期（ZIP・試行・何周期目か）を確認し、「この周期を除外」を押します。自動で再解析されます。
  3. 除外した周期は「除外した周期」に表示され、「戻す」で元に戻せます。

除外した周期は、関節角度・身体重心・時間距離因子・Excel 出力の全てから除かれます。 歩行速度は試行単位で求めるため、周期を除外しても変わりません。

9. Excel出力

「Excelをダウンロード」で結果を保存します。ファイル名は、1 試行のみの場合 [ZIP名]_[MOT名].xlsx、 複数試行の場合 OpenCapGait_[試行数]trials_[日時].xlsx です。シートの内容は7. Excel出力の内容を参照してください。

5. 用語と歩行周期

このアプリでは、同じ側の IC から次の同じ側の IC までを 1 歩行周期（0〜100%）とします。 下の図は右脚を基準とした一般的な歩行周期の例です（割合は目安）。

用語意味（このアプリでの定義）
IC（Initial Contact）初期接地。足が床に最初に接地した瞬間
Toe Off（TO）つま先離地。つま先が床から離れた瞬間
歩行周期 / %GC同側の IC から次の同側の IC まで。%GC はその中の位置（Gait Cycle %）
立脚時間IC → 同側の Toe Off
遊脚時間同側の Toe Off → 次の同側の IC
荷重応答期時間IC → 反対側の Toe Off（第1両脚支持期）
前遊脚期時間反対側の IC → 同側の Toe Off（第2両脚支持期）
歩幅（step length）反対側の IC 時の反対側の踵から、同側の IC 時の同側の踵までの進行方向の距離。重複歩距離（stride length）とは異なります
歩行速度左右を分けない全体の値（算出方法は次の章）

6. 算出方法（研究で使う方向け）

関節角度と時間正規化

  • 使用する変数: 右 hip_flexion_r・knee_angle_r・ankle_angle_r、左は _l（OpenSim の座標。股関節は屈曲、膝関節は屈曲、足関節は背屈が正）。
  • 各歩行周期（両端の IC のサンプルを含む）を MOT の time に基づいて 0〜100% とし、1% 刻みの 101 点へ線形補間します。0% と 100% は元の IC の値と一致させています。
  • 平均 ± SD は、全試行・全 ZIP の周期をまとめて側ごとに求めます。SD は標本標準偏差（n−1）で、1 周期のみの場合は空欄です。
  • MOT の全変数（骨盤・体幹・上肢を含む）も同じ方法で正規化し、Excel に出力します。

時間距離因子

定義は OpenCap 公式の解析コード（opencap-processing の gait_analysis.py）に合わせています。

  • 歩幅: 踵マーカー（r_calc_study / L_calc_study）の位置を、周期ごとの進行方向へ投影して求めます。マーカーは ZIP 内の TRC（OpenCap の実測値）を優先し、ない場合はモデルから計算した位置を使います。
  • 歩行速度: 試行ごとに、最初の IC から最後の IC まで（左右問わず）の身体重心の水平移動距離 ÷ 時間を求め、試行間で平均します（n = 試行数）。身体重心が算出できない場合は骨盤マーカー（ASIS・PSIS）の中心を使います。
  • 時間因子: イベントの MOT 時刻の差から求め、歩行周期に対する割合（%GC）も出力します。必要なイベントが周期内にない項目は空欄とし、平均の計算から除きます。

身体重心（COM）

  • ZIP 内のスケーリング済み OpenSim モデル（.osim）と MOT の関節座標から、ブラウザ上で各体節の位置を計算し（順運動学）、全体節の質量で重み付けした平均として求めます。OpenSim の calcMassCenterPosition と同じ定義です。
  • 座標: 鉛直は地面座標系の Y（床がほぼ 0 = 床からの高さ）。前後は周期ごとの身体重心の水平移動の向き、左右はそれに直交する向き（右が正）です。グラフは原点からの位置（m）で表示します。
  • OpenCap の水平方向の原点は撮影時のキャリブレーションボードの位置で決まるため、左右位置の絶対値は試行間・被験者間で比較できません。比較には変位幅（cm）を使ってください。
  • 速度は位置の中心差分で求め、追加のフィルタ処理はしていません。
  • 検証: 実データで、モデル上のマーカー位置と実測マーカーの差は RMS 約 2 cm（下肢 0.7〜1 cm）、モデルの総質量は体重と一致しました。

7. Excel出力の内容

各周期の行には、どの ZIP・試行のデータか（ZIP file・Trial・Cycle in trial）が記録されます。

シート内容
Graphs関節角度 3 つと身体重心 2 つのグラフ画像
Gait_Events設定した全イベント（側・種類・サンプル・MOT時刻・動画時刻）
Cycles周期ごとの時刻・周期時間・立脚期%・時間距離因子・身体重心の変位幅と、側ごとの平均/SD
Spatiotemporal時間距離因子の要約（歩行速度は全体、その他は左右別の平均・SD・n）
Trials試行ごとの周期数・除外数・歩行速度、使用したモデルとマーカーの出所
Normalized_Data関節角度の 101 点データ（側ごとの平均・SD と、各周期 C1, C2, … の値）
Original_Data各周期の正規化前のデータ（サンプル・時刻・%GC・角度）
Metadata解析条件・定義・対象試行の一覧・バージョン・出力日時
Normalized_All_DataMOT の全変数を周期ごとに 101 点へ正規化したデータ
COM_Normalized身体重心の 101 点データ（位置・変位・速度、地面座標系の X/Y/Z）。全試行で算出できた場合のみ
Excluded_Cyclesグラフから除外した周期の一覧

Normalized_Data の周期番号（C1, C2, …）が、どの ZIP・試行の何周期目かは Cycles シートで確認できます。

8. 注意点・よくある質問

ページを再読み込みしたら設定が消えました
読み込んだ ZIP・設定したイベント・除外した周期はブラウザの中にだけ保持され、再読み込みや画面を閉じると消えます。作業の区切りで Excel を出力しておいてください。
データはどこかに送信されますか
送信されません。ZIP の読み込みから解析・Excel 作成まで、全てお使いのブラウザ内で行います。
「解析実行」が押せません
同じ側の IC を 2 回以上設定した試行が 1 つもないと押せません。5. の「歩行周期」の表に周期が表示されているか確認してください。
荷重応答期や歩幅が「-」になります
その周期内に反対側の IC・Toe Off が設定されていないと算出できません。歩幅には踵マーカー（TRC またはモデル）も必要です。
身体重心が表示されません
ZIP にモデル（.osim）がない試行が 1 つでもあると、身体重心の解析は行いません（関節角度・時間距離因子は解析されます）。2. の表示で原因を確認できます。
グラフの細線がうまく選べません
線が重なっている場合はクリック位置に最も近い線が選ばれます。選択中の表示で ZIP・試行・周期を確認するか、上部の「歩行周期」の一覧から選んでください。
トレッドミル歩行や足踏みでも使えますか
関節角度と時間因子は解析できます。身体重心がほとんど水平移動しない場合は進行方向を決められないため、歩幅・歩行速度・身体重心の前後/左右成分は参考値（または空欄）になります。
大きな ZIP の読み込みが遅いです
動画は表示するカメラの分だけ展開します。複数の ZIP を扱う場合、表示するカメラを 1 台にすると軽くなります。
